## 🚀 Featured Client Case Studies & Production Systems

### 1. ⚖️ **Aquino & Co. Law Firm — 24/7 Legal Intake & Consultation Engine**
- **Client**: Aquino & Co. Law Firm (Santiago, Isabela, Philippines)
- **Challenge**: Fragmented inquiries across walk-ins, phone calls, and manual Facebook chats resulting in missed consultations and delayed follow-ups.
- **Engineered Solution**:
  - Direct responsive client intake portal with case categorization.
  - Serverless Google Apps Script backend routing data into a structured Google Sheets database.
  - Automated HTML email dispatch alerting both firm attorneys and prospective clients in real-time.
  - GCash payment verification pipeline with automated reference logging.
- **Business Impact**: 100% elimination of double-booked consultations; client response time slashed from 4 hours to under 30 seconds.

### 2. 🏖️ **The Upper Room Staycation — Hospitality Direct Booking & Voucher Engine**
- **Client**: The Upper Room Staycation
- **Challenge**: High 15–20% commission fee leakage from third-party travel platforms (OTAs) and calendar management overhead.
- **Engineered Solution**:
  - Custom multi-step direct booking engine with instant date availability verification.
  - Promo voucher system with automatic discount recalculation and burn-lock tracking.
  - Secure Base64 client ID and GCash payment receipt upload directly to private Google Drive folders.
  - Dual-party automated confirmation dispatch with custom booking reference codes.
- **Business Impact**: ₱0 monthly recurring software overhead; high-margin direct guest capture.

### 3. 🎓 **Toppers Tutorial Center — Student Enrollment Accelerator**
- **Client**: Toppers Tutorial Center
- **Challenge**: High drop-off during manual enrollment intake and complex multi-subject course tracking.
- **Engineered Solution**:
  - High-converting academic registration funnel connected to a GoHighLevel pipeline.
  - Automated SMS and email reminder sequences for parent onboarding.
  - Multi-subject course selection intake with dynamic pricing calculation.
- **Business Impact**: Streamlined parent enrollment with a 40%+ boost in completed student registrations.

### 4. ✈️ **Clear Sky Travel & Tours — Multi-Destination Reservation Engine**
- **Client**: Clear Sky Travel and Tours
- **Challenge**: Custom quote requests required tedious back-and-forth messaging across various social platforms.
- **Engineered Solution**:
  - Interactive destination package browser with multi-tier pricing.
  - Dynamic travel preference capture (passenger count, hotel tier, flight add-ons).
  - Automated inquiry routing into centralized operational spreadsheets.

### 5. 🤖 **Autonomous AI Assistants & Chatbots**
- **Facebook Page AI Agent**: Autonomous Meta Graph API customer assistant qualifying prospect budgets, answering FAQs, and booking meetings directly to Google Calendar.
- **Slack AI Assistant**: Intelligent workspace coworker connected to internal tools for rapid team data retrieval and query resolution.
- **Brian AI (Telegram Bot)**: 24/7 autonomous messaging assistant handling customer inquiries and operational triage.

## 💻 Local Development Setup

To run and preview this portfolio locally:

### Option 1: VS Code Live Server
1. Open this directory in **Visual Studio Code**.
2. Right-click [`index.html`](file:///c:/Users/joyce/ObsidianVault/10-19%20Projects/13%20Personal%20Builds%20%28Apps%20-%20Tools%20-%20Side%20Projects%29/0777.%20NEW/index.html) and select **"Open with Live Server"**.
3. View the app at `http://localhost:5500`.

### Option 2: Python Static Server
Run in PowerShell:
```powershell
python -m http.server 5190
```
Open your browser and navigate to `http://localhost:5190`.

### Option 3: Node `npx serve`
```powershell
npx -y serve .
```

## 🌐 Production Deployment

The project is structured as a zero-dependency, ultra-fast static web application optimized for deployment to:
- **Netlify**: Connect your GitHub repository, set publish directory to `.`, and configure custom domain `joyceyap.com`.
- **Vercel**: Deploy with `vercel --prod` for edge caching and instantaneous CDN propagation.
- **GitHub Pages**: Deploy the `main` branch to GitHub Pages with custom domain CNAME record pointing to `joyceyap.com`.
